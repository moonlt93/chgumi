# 로컬 운영과 제출

## 실행

Node.js 22 이상과 npm이 필요하다. ZIP을 풀고 프로젝트 폴더에서 실행한다. 최초 npm ci는 인터넷 연결이 필요하다.

```bash
npm ci
npm run build -- --webpack
npm start
```

http://localhost:3000 에서 페르소나를 정하고 오늘의 실천을 기록한다. 기본 코인은 0이며 코디 또는 활동 기록 후 20코인으로 화분을 살 수 있다. 내 방 → 방과 캐릭터 꾸미기 → 적용으로 배치한다. 숍 미리보기는 저장되지 않는다.

## 저장과 운영 범위

- 별도 DB/Redis, Docker, CDN, 3D 에셋 서버가 없다. 캐릭터와 방은 CSS 3D 블록으로 표시하며, 옆벽 없이 정면에서 바라보는 고정 구도다.
- 기본 저장 위치는 data/users. LIFE_DATA_DIR로 변경 가능하다. 서버 프로세스에 읽기/쓰기 권한이 있어야 한다.
- 사용자별 JSON에 프로필, 기록, 보상 원장, 재화, 보유/장착 상태를 함께 저장한다. 임시 파일 후 rename으로 교체한다.
- 하나의 Node 프로세스에서만 실행한다. 여러 인스턴스·서버리스·임시 디스크는 지원하지 않는다.
- 임의 ID의 HttpOnly/SameSite 쿠키로 브라우저를 식별한다. HTTPS에서는 Secure를 설정한다. 로컬 HTTP에서도 실행 가능하다.
- 로그인/다른 기기 동기화/쿠키 분실 복구는 없다. 쿠키를 삭제하면 새 사용자로 시작한다. 공용 브라우저에서는 같은 사용자 데이터가 보인다.
- 서버를 중지하고 data/users를 별도 안전한 경로에 복사해 백업한다. 배포/제출 ZIP에 실제 데이터를 넣지 않는다.
- 저장 파일이 손상되면 초기화하지 않고 오류를 반환한다. 백업으로 복원해야 한다.
- 이것은 개인/심사용 로컬 운영 MVP다. 인터넷 공개 서비스에 필요한 계정 복구, 속도 제한, 운영 모니터링, 접근 제어 강화는 별도 작업이다.

## 보상 규칙

한국 시간 기준 코디/활동 각각 20 XP·20코인, 직접 기록 10 XP·10코인. 종류별 하루 한 번이며 최대 50 XP·50코인. 한 행위를 여러 종류로 기록하지 않도록 안내하지만 현실 행동의 동일성은 인증하지 않는다. 하루 기록은 삭제분 포함 최대 20개다.

기록 수정·삭제로 보상은 변하지 않는다. 삭제 시 본문은 비우며 중복 보상 방지를 위한 ID와 보상 원장은 유지한다. 구매 시 경험치는 줄지 않고 코인만 차감된다. 실패한 요청은 상태를 저장하지 않으며, 이미 보유한 상품의 구매 재시도는 추가 차감하지 않는다.

## 데모와 AI

기본 홈의 코디·페르소나별 활동은 준비된 샘플이며 데모 표시가 있다. 포인트/구매/저장은 실제로 동작한다. 기록 피드백은 저장하지만 새로운 AI 활동 추천에는 아직 반영하지 않는다.

.env.local에 OPENAI_API_KEY를 설정하면 오늘 화면에서 기존 /photo 스타일 생성으로 이동할 수 있다. 해당 경로는 실제 유료 API를 호출한다. 키는 제출 파일에 포함하지 않는다. 사진 기반 생성 이미지는 아바타용 3D 의상으로 변환되지 않는다.

## 검증과 ZIP

```bash
npm run verify
npm run package:submission
```

패키징에는 Python 3 표준 라이브러리를 사용한다. artifacts/chugumi-mvp.zip에 소스/정적 파일/잠금 파일/문서를 담는다. node_modules, .next, 실제 환경 파일, data, .git은 제외한다. ZIP은 다른 폴더에 풀어 npm ci 후 실행한다.
