# 페르소나·기록 기반 ReAct 코치

## 목표

API 키를 설정하고 버튼을 누르면, 현재 사용자의 페르소나와 최근 기록을 조회하는 도구 반복을 거쳐 코디·활동을 제안한다. ZIP/단일 프로세스/파일 저장 구조를 유지한다.

## 완료 조건

- 읽기 전용 도구를 모델이 선택하고, 서버가 실행 결과를 다음 모델 호출에 전달한다.
- 페르소나·최근 기록 두 도구를 사용하지 않은 최종 응답은 거부한다.
- 구조화 출력과 서버 검증, 최대 4회 모델 호출·6회 도구 호출·45초 제한.
- 사용자 쿠키로 조회 대상을 고정하고, 다른 사용자 ID나 파일 경로를 도구 인자로 받지 않는다.
- 같은 입력/날짜/모델의 결과를 사용자 JSON에 캐시한다. 변경 중 생성된 결과는 저장하지 않는다.
- 사용자별 하루 최대 5회 시도, 요청 간격 1분. 한도는 실패도 포함하며 파일에 보관한다.
- 명시적 버튼 요청만 API 호출. 사용자에게 전송 데이터와 비용 발생을 안내한다.
- 키 없음/응답 오류 시 샘플 제안 유지. AI 제안으로 기록해도 보상은 기존 서버 규칙만 적용.

## 검증

도구 왕복, 필수 도구 누락, 허용하지 않은 도구/인자, 반복 한도, 잘못된 출력, 인증 실패, 캐시/한도/동시 요청을 모킹 테스트로 검증했다. 최초 구현 당시 전체 40개 테스트와 webpack 빌드가 통과했다. 후속 Supabase 저장소와 Vercel 환경 분리는 vercel-supabase.md에 기록한다. 이후 사용자 행동 반복 구조와 실제 키 호출 시도(429 실패)는 coach-feedback-loop.md에 기록한다.
