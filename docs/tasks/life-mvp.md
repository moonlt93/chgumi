# 실천과 공간 성장 MVP

## 목표와 범위

별도 DB/Redis 없이 ZIP 제출 가능한 단일 Next.js 앱. 페르소나 → 실천 기록 → 경험치/코인 → 숍 → 방·캐릭터 꾸미기를 연결한다.

## 구현

- 사용자별 JSON과 임의 쿠키 ID, 원자적 교체 및 사용자별 프로세스 내 쓰기 직렬화.
- 한국 날짜 기준 종류별 하루 1회 보상. 기록 ID 재전송 중복 방지, 삭제 후 보상 원장 유지.
- 잔액 검증, 구매와 차감 함께 저장, 보유 물품만 장착.
- 키 없는 샘플 코디와 페르소나별 고정 활동 제안. AI 사용 가능 시 기존 사진 생성 흐름 연결.
- 별도 에셋 다운로드 없는 CSS 3D 블록 캐릭터/정면 고정 시점 방(옆벽 제거). 의상 색상과 가구 슬롯 교체.
- 기록 수정/삭제 및 보관함, 구매 전 공간 미리보기.

## 검증

- npm run verify 통과: 포맷, lint, TypeScript, 테스트 27개, webpack 프로덕션 빌드.
- 새 회귀 사례 6개: 기록 재전송/삭제 후 중복 보상 방지, 동시 구매/잔액, 날짜 경계, 입력 위조/사용자 분리, 손상 파일 보존.
- 브라우저: 페르소나 저장 → 샘플 코디 기록 → 20코인 지급 → 화분 구매 → 배치 성공. 부족한 잔액의 구매 오류 표시 확인.
- 서버 재시작/새로고침 후 프로필·기록·경험치·보유/장착 상태 유지 확인. 브라우저 콘솔 오류 없음.
- HTTP: 다른 Origin 403, 잘못된 JSON 400, 8KB 초과 입력 400 확인.
- 제출 ZIP 추출본에서 npm ci --offline와 webpack 빌드 성공. 후속 화면 수정본은 본 프로젝트 verify 통과 후 최종 ZIP 재생성.
- 이미지 생성 유료 API는 실행하지 않음. 키 없는 데모로 검증.

## 제약

단일 프로세스/영속 로컬 디스크, 쿠키 삭제 시 기존 사용자 연결 복구 불가. 공개 다중 서버 서비스용 계정·복구·분산 잠금 없음. 활동 추천은 고정 데모이며 AI 개인화 추천·사진 첨부·자유 배치·실제 3D 의상 메시·가상 피팅은 이 범위에서 제외한다. 현실 행동은 자기 신고이며 사진 인증을 하지 않는다.
