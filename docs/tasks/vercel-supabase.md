# Vercel Supabase 연결

## 목표

Vercel 배포에서 방·활동·코인·구매 내역을 영속 저장하고 환경별 API 호출을 분리한다.

## 범위와 완료 조건

- Life/Coach 저장소를 Supabase REST API로 연결한다. 키 없는 로컬은 기존 파일 저장소를 사용한다.
- Vercel에서 설정 누락 시 파일 저장으로 넘어가지 않는다.
- SQL의 revision 비교로 동시 갱신 손실을 막고 충돌 시 최신 상태로 규칙을 다시 계산한다.
- 사진 생성의 실험 저장소는 별도이며 이번 전환 범위에 포함하지 않는다.

## 구현 계획

1. 사용자별 JSON 상태를 PostgreSQL 한 행으로 저장해 기존 규칙을 유지한다.
2. 서버 키만 접근하도록 테이블 RLS와 권한을 제한한다.
3. 단위 테스트, 실제 Supabase 테스트 사용자, check/build, 브라우저, 가능하면 실제 배포를 검증한다.

## 결과

- 초기 Supabase 인증 HTTP 200 확인. SQL 적용 완료 사용자 응답 수신.
- 실제 저장·재조회·중복 기록·동시 구매·사용자 격리 테스트 통과. 해당 스크립트의 테스트 데이터 삭제 완료.
- 도메인/환경/저장소 회귀 테스트 및 프로덕션 빌드 통과. 로컬 브라우저에서 Supabase 프로필 저장과 새로고침 유지 확인.
- 사용자 요청에 따라 실제 Vercel 배포는 하지 않았다. 운영 기본 도메인은 https://chgumi.vercel.app, Preview는 VERCEL_URL, 로컬은 요청 출처를 사용한다.
