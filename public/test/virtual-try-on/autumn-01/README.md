# autumn-01: 가을 오버셔츠 착장 샘플

실제 인물이 아닌 AI 생성 성인 남성과 AI 생성 의류로 만든 테스트 자료다. 모든 이미지는 Codex 내장 image_gen으로 생성했다. 전체 프롬프트와 입력 경로는 `case.json`에 있다.

| 파일 | 용도 |
| --- | --- |
| person.png | 인물 입력: 회색 티셔츠, 차콜 바지, 흰 운동화 |
| garment.png | 의류 입력: 올리브 트윌 오버셔츠 |
| try-on-sample.png | 두 이미지를 참조해 생성한 비교용 착장 결과. 정답 데이터가 아님 |

## 실행한 실험과 관찰

인물·의류를 각각 생성하고, 두 이미지를 함께 참조하는 이미지 편집을 1회 실행했다. 결과를 육안으로 확인했을 때 얼굴·헤어·전체 포즈와 바지·신발·배경이 대체로 유지되었다. 중앙 단추 5개와 가슴 플랩 주머니 2개가 표현되었다. 옷의 색상 밝기와 주름은 참조 이미지와 차이가 있어 상품 색상·소재의 정확한 재현으로 판정하지 않는다. 픽셀 단위 동일성이나 신체 치수는 측정하지 않았다.

현재 앱의 이미지 생성 포트와 요청 파서는 인물 사진 한 장을 받으며 의류 참조 입력은 지원하지 않는다. 앱 E2E, 전용 가상 피팅 모델, 자동 평가기는 이 실험에서 실행하지 않았다.

## 테스트에 사용하는 방법

- 현재 앱 업로드 검증: `person.png`를 인물 사진으로 사용한다.
- 가상 피팅 기능 구현 후: `case.json`의 두 inputs를 함께 전달하고 checks 항목을 확인한다.
- 모킹한 응답·비교 UI 검증: `try-on-sample.png`를 응답 fixture로 사용할 수 있다. 이 경우 실제 모델 생성 성공으로 집계하지 않는다.
- 생성 결과는 매번 달라질 수 있으므로 비교용 샘플과의 픽셀 일치 여부를 모델 품질 통과 기준으로 사용하지 않는다.

개발 서버에서 `/test/virtual-try-on/autumn-01/person.png`, `/test/virtual-try-on/autumn-01/garment.png`, `/test/virtual-try-on/autumn-01/try-on-sample.png`로 접근할 수 있다. public 아래 파일은 배포 시에도 공개된다.
